# FERRAZ — дизайн-концепт

Демонстрационная версия сайта барбершопа FERRAZ в Альметьевске.

Статические HTML, CSS и JavaScript. Фотографии сгенерированы для концепта и не показывают реальный интерьер или сотрудников FERRAZ. Запись демонстрационная: контактные данные не собираются, заявка не отправляется, реальное время не резервируется.

Шрифты Manrope и Oswald используются по SIL Open Font License; лицензии находятся в `assets/`.

Для локального просмотра достаточно открыть `index.html` или запустить простой статический сервер. GitHub Pages публикует корень ветки `main` без этапа сборки.
